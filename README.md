## 🩸 AkameBot Lite
Versión ligera de AkameBot enfocada en administración, protección de grupos, juegos sencillos, economía básica, stickers y utilidades.

- 🇻🇪 Hecho en Venezuela por Gabriel-V.
- ⚡ Comandos con o sin prefijo.
- 💴 Moneda: Yen (¥).
- 🛡️ Antiprivado y AntiLink activos de fábrica.
- 🚫 Sin descargas, reproductores, TikTok, Pinterest, audios automáticos ni sistema de ventas.

## 🛡️ Administración
AntiLink, AntiSpam, AntiFalsos, bienvenida, modo administrador, mute, expulsiones, promoción, advertencias, invocación y gestión del grupo.

**AntiLink y Antiprivado parten activos.** Bienvenida y Modo Admin parten desactivados.

## 🎮 Juegos
`trivia`, `reto`, `verdad` y `parejas`.

## 💴 Economía
Economía básica con los valores establecidos para AkameBot VIP.

- Registro inicial: **¥50**.
- `.w` / `.trabajo`: ingreso con espera de **10 minutos**.
- `.daily`: **¥1000 diarios**.
- `.robar @`: espera de **10 minutos**.
- Sticker de vídeo: **¥1**.
- Sticker desde foto: **¥1**.
- Banco, depósito, retiro y transferencia.
- Rankings de dinero, nivel, rango y reputación.

## 🖼️ Stickers
`.s` / `.sticker` crea stickers de imágenes o vídeos cortos. `.toimg` convierte stickers a imagen.

## 📱 Instalación en Termux
Si no tienes Termux, puedes instalarlo desde la **Google Play Store oficial**:
https://play.google.com/store/apps/details?id=com.termux

Después, copia y pega el comando completo. La instalación acepta automáticamente las confirmaciones; al finalizar solo tendrás que introducir tu número.

```bash
pkg update -y && pkg upgrade -y && pkg install git nodejs-lts ffmpeg wget tesseract -y && echo "y" | termux-setup-storage && rm -rf AkameBot_Lite-MD && git clone https://github.com/GabrielVB26/AkameBot_Lite-MD && cd AkameBot_Lite-MD && npm install && npm start
```
